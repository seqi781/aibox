## 如何申请

个人下载和本地使用无需提交申请。需要源码改作、组织部署、转载、分发、售卖或其他超范围许可时，通过[官方仓库 Issues](https://github.com/seqi781/aibox/issues)联系维护者，说明版本、行为和范围。额外授权应由有权授权的著作权人明确书面给出；提交请求、没有收到回复或向第三方购买服务，不代表已经获准。

不需要在公开 Issue 中提供账号密码、API Key、节点、个人证件或其他敏感信息。

## 为什么不能写“禁止所有 Fork”

GitHub 的公开仓库规则允许站内浏览和 Fork。项目许可不能覆盖平台上已经授予的权利，也不能从技术上阻止他人下载公开代码。若目标是限制谁能取得源代码，需要另行决定是否改为私有仓库；增加本文件不会自动改变可见性。

依据：[GitHub 公开仓库授权规则](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#5-license-grant-to-other-users)、[GitHub 许可说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)。

本声明不追溯撤销此前明确、合法授予的许可。旧版本或其他著作权人的授权范围，仍需依据当时的实际条款确定。
