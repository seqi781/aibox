# 本机与 aibox 对比

[文档目录](README.md) · [使用指南](GUIDE.md) · [保护边界](ARCHITECTURE.md)

```bash
aibox compare
```

本机和正在运行的 aibox 并排显示实际数据。它不启动或重建容器、不修改配置，也不读取 Claude 的账号、密钥或对话。

## 怎么看表格

| 标记 | 含义 |
|---|---|
| `✓ ≠` | 两边数据不同；不同不等于匿名 |
| `✓ 受限` | 检测到相应目录或权限受到限制 |
| `⚠ =` | 两边数据相同 |
| `⚠ 可见` | 该信息仍然可以读取 |
| `—` | 未取到、无法直接比较，或本次未做该项验证 |

显示的是当前终端及容器可接触的信息，不表示 Claude 已读取或上传，也不能换算为封号概率。

| 字段 | 数据含义 |
|---|---|
| IPv4 / IPv6 | 两边各自查到的当前网络出口，不一定是本机真实宽带 IP |
| 系统、内核、CPU、内存 | 当前运行环境可读到的数据；内存用 GiB 显示 |
| 电脑名、UID:GID | 实际电脑名和用户编号；编号对齐用于保证项目文件归属正确 |
| 机器 ID、开机 ID | 仅显示前 8 位；macOS 没有同类 Linux 标识时不能直接比较 |
| 硬件目录 | `/sys` 是否可读、只读遮挡是否实际存在 |
| 本机文件 | 实际挂入容器的本机目录或文件数量，分别列出可写和只读 |
| 本机路径 | 是否在环境提示或挂载信息中发现本机用户目录路径；“未发现”不代表已排除所有途径 |
| 网络权限、网关 | 实际容器权限和是否接入健康网关；健康不等于已模拟断线 |

长数据会随终端列宽截断，避免表格错位。机器 ID 前缀与电脑名仍可能关联环境，不应直接公开。

## 输出选项

| 命令 | 用途 |
|---|---|
| `aibox compare` | 默认实际数据表 |
| `aibox compare --redact` | 隐藏 IP、电脑名和 ID，适合截图分享 |
| `aibox compare --offline` | 跳过第三方 IP 查询，检查本地信息和容器配置 |
| `aibox compare --json` | 脱敏的结构化结果，供脚本处理 |

选项可组合，例如 `aibox compare --offline --redact`。

默认向 `api.ipify.org` / `api6.ipify.org` 查询两边出口，检测网站会看到相应请求来源。本机数据在本机进程内比较，不传进容器；命令不自动保存报告，但终端记录或手动重定向仍可能保存实际数据。

返回 `0` 表示检查已完成，包括主动跳过的联网查询；不表示没有暴露项。参数错误、环境不可用或 IP 查询不完整时返回 `2`，看具体未验证项。

## 容易误读的结果

- **IP 相同**：本机也可能在用同一节点，不能仅凭这一项认定直连泄漏。没有取到真实宽带出口时，应保留“尚无法确认”的结论。
- **IPv6 未连通**：网络故障也会导致失败，不能单独证明防护生效。
- **网关 healthy**：只说明当前健康检查通过。需要验证断线保护时另行运行 `aibox doctor --full`；该操作会临时中断 aibox 网络。
- **没有挂载项目**：表示本机目录没有开放，不代表容器不能读取自己的系统文件。
- **用户编号或 CPU 相同**：这些通常不是唯一身份标识，但 aibox 也不会隐藏它们。

## 硬件防护与旧容器

默认使用独立机器标识，并用只读空目录遮住 `/sys`。它不修改 CPU 指令、内核返回值或 Linux 共享开机标识，也不能保证工具识别不出容器。

更新脚本后，旧容器不会自动获得新镜像或新挂载。先保存任务，再由维护者重建工作镜像和容器；对比命令只检查状态，不会替你中断任务。纯粹重启同一旧镜像不等于完成镜像更新。

需要读取 `/sys` 的 GPU、设备发现和硬件监控工具可能受影响。这类项目可把 `config/aibox.env` 的 `AIBOX_HIDE_HARDWARE` 设为 `0`，在保存任务后重建工作容器；表格会如实显示硬件目录仍然可读。

独立机器标识保存在该环境自己的 home 中，保留 home 时维持不变。停止容器不会清除登录或命令历史，使用相同账号仍可能关联身份。
